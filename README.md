# 📊 Retail Inventory Dashboard in Excel

## About the Project

This project is an interactive Retail Inventory Dashboard created using Microsoft Excel. The goal was to practice data analysis using Pivot Tables, Pivot Charts, and Slicers while working with a retail inventory dataset.

The dashboard makes it easy to analyze products, suppliers, inventory, and sales by applying different filters and viewing the results instantly.

---

## Dataset

The dataset contains 1,000 retail inventory records with details such as:

- Product ID
- Product Name
- Category
- Supplier Name
- Unit Cost
- Retail Price
- Opening Stock
- Units Sold
- Closing Stock
- Reorder Point
- Stock Status

---

## Dashboard Insights

The dashboard helps answer questions like:

- How many products are available in each category?
- Which supplier provides the most products?
- Which category has the highest units sold?
- What is the average retail price and unit cost by category?
- Which supplier has the highest opening stock?
- Which supplier sold the highest number of units?
- How does the data change when filtered by category or stock status?
